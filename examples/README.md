# examples/

外部連携のサンプルコードです。**本体の動作には不要**で、テストの対象にも含めていません。
そのまま設置するのではなく、自分の環境に合わせて書き換えて使ってください。

| ファイル | 内容 |
| --- | --- |
| `slack_integration_sample.php` | Slack とドアベルのあいだに立つ中継。通知を Block Kit のボタン付きメッセージに変換し、押されたボタンで応答を返す |

## 通知を Slack に流すだけなら中継は要りません

外部連携の**通知先URL**に Slack の Incoming Webhook URL をそのまま指定すれば、
中継なしでメッセージが届きます（通知のペイロードに Slack が本文として扱う `text` が入っています）。

中継が必要になるのは、**Slack のボタンで応答まで行う場合**だけです。
